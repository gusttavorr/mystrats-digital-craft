=== ANIMAÇÕES & EFEITOS ===

ANIMAÇÕES OBRIGATÓRIAS:

SCROLL:

- Usar Intersection Observer para revelar elementos (fade-up, slide-in)

- Parallax sutil no hero (background move 0.3x scroll speed)

- Contador numérico animado quando entrar na viewport

CURSOR:

- Cursor customizado: círculo branco que segue o mouse com lag

- No hover de links/botões: cursor expande + muda cor

TEXTO:

- Hero title: efeito "text scramble" (letras trocam rapidamente antes de revelar)

- OU typewriter effect com cursor piscando

- Números contando de 0 até o valor final (duração: 2s)

CARDS:

- Hover: translateY(-8px) + box-shadow 0 20px 40px rgba(0,0,0,0.5)

- Borda que "acende" (border-color de transparente para rgba(255,255,255,0.3))

TRANSIÇÕES DE PÁGINA:

=== RESPONSIVIDADE & PERFORMANCE ===

RESPONSIVIDADE:

Mobile (< 768px):

- Hero: stack vertical, texto menor, CTA empilhado

- Navbar: hamburger menu com drawer lateral (slide-in da direita)

- Grid de serviços: 1 coluna

- Grid de serviços: 2 colunas

- Grid portfólio: 2 colunas

- Hero: centralizado com imagem menor

Desktop (> 1024px):

- Grid de serviços: 3 colunas

- Grid portfólio: 3 colunas

- Cursor customizado ativado

- Imagens: formato WebP + lazy loading

- Fontes: preconnect + font-display: swap
